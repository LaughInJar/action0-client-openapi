# Changelog

All notable changes to action0-client-openapi are listed here. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
version numbers follow [Semantic Versioning](https://semver.org/).

## Unreleased

### Fixed

- Parameters and body properties named like a method or class attribute
  of action0-client's operation classes are now renamed with a trailing
  underscore, as `method` and `path` already were: `request_options`,
  `as_request`, `parse`, `check`, `load`, `load_json`, `serialize_value`
  and `serialize_json_value`. The wire name is unchanged
  (`check_: bool = query("check")`).

  Before, such a field replaced the method of the same name, and every
  send of the generated operation failed with a `TypeError`.
  action0-client 0.2.0 refuses such classes when they are defined, so
  code generated by an older version of this tool for an API with such
  a parameter no longer imports there. Regenerate it; no other generated
  code changes.

## 0.1.2 — 2026-08-15

### Added

- Typed exceptions for documented error responses.
- Non-exploded array query parameters are joined into one value.

## 0.1.1 — 2026-08-15

### Added

- The base URL falls back to path- and operation-level `servers`.
- A catch-all field for `additionalProperties` next to `properties`.

### Fixed

- Digits stay attached to acronym runs when names are split.

## 0.1.0 — 2026-08-15

First release: generates typed operations, models and a client class for
action0-client from an OpenAPI 3.x schema.
